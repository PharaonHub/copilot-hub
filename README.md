# Copilot Hub

Copilot Hub is a focused marketplace containing the BMAD Method workflow plugin for GitHub Copilot.

## Included plugin

- [`bmad`](plugins/bmad/README.md): discovery, product planning, architecture, delivery, implementation, QA, and review workflows.

## Installation

Point your Copilot marketplace configuration at this repository. The collection manifest is [`marketplace.json`](marketplace.json), and it registers the plugin at `./plugins/bmad`.
